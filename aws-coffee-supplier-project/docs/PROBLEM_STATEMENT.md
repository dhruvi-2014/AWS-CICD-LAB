# Problem Statement

The application requires a reliable way to host the Coffee Supplier Management system in an AWS environment and deploy application updates in a structured manner.

The project addresses the need to:

- host the application in AWS;
- display supplier information to customers;
- allow administrators to add and edit supplier records;
- store and retrieve supplier data;
- update customer-related functionality as a microservice; and
- deploy the update through a repeatable Source-to-Deploy workflow.
