# Project Summary

The project is a Coffee Supplier Management web application designed as a practical reference implementation for the AWS Skill Builder activity documented in the accompanying report.

The application provides customer and administrator views for supplier information and includes a separate customer microservice with deployment assets for an EC2-based environment.

The activity evidence documents an AWS EC2-hosted application, supplier database operations, a pipeline named `update-customer-microservice`, and a successful replacement deployment receiving 100% traffic.
