# Implementation Steps

1. Set up the AWS environment and EC2 compute instance.
2. Deploy and access the Coffee Supplier Management application.
3. Configure and verify supplier data.
4. Verify application files and configuration.
5. Test customer and administrator interfaces.
6. Prepare the customer microservice update.
7. Configure the `update-customer-microservice` deployment pipeline.
8. Execute the deployment.
9. Shift traffic to the replacement version.
10. Perform final application verification.

For the reproducible repository version, the same workflow can be tested locally with Node.js and Docker, then adapted to an AWS EC2 + CodeDeploy environment using the supplied deployment files.
